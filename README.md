MIPS Grade Calculator

Description:

A grade calculator written in MIPS assembly and tested using the MARS simulator.

The program asks the user for two midterm scores and one final exam score. It calculates the average and determines the corresponding letter grade.

Features:
- Accepts three exam scores

- Calculates the average

- Determines the letter grade

- Uses separate procedures for calculating the average and letter grade

Technologies:
MIPS Assembly •
MARS Simulator
